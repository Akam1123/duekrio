Privacy & data storage

Your invoice workspace stays in your browser.

A clear explanation of the current release, so you can decide what information belongs here.

Last updated September 25, 2026

What the app stores

When you import a CSV, add an invoice, or write a follow-up note, PromiseLedger stores that workspace in your browser's local storage on this device. The workspace can include customer names, invoice numbers, email addresses, amounts, dates, owners, blockers, and notes that you choose to enter.

The current app has no account system, cloud sync, server-side backup, analytics script, or automatic email sending. Its code runs in your browser. We do not receive your imported invoices or notes through an application server.

Back up your work.

Browser storage can be lost if you clear site data, change browsers, use private browsing, or switch devices. Choose Backup JSON in the workspace and store the file according to your firm's security policy. You can restore that file later.

What the host may see

The website is currently served by GitHub Pages. Like other web hosts, GitHub may record request information such as your IP address when you visit. GitHub describes this in its privacy statement. The public source code is available on GitHub.

What happens when you use external actions

Open email app creates a draft in your own email software. Copy draft copies text to your clipboard. Nothing is sent automatically. Backup JSON and Export CSV create files on your device. If you open a GitHub feedback link, you leave PromiseLedger and GitHub's own policies apply.

Who can access the stored workspace

Someone with access to your browser profile or exported backup file may be able to read your data. Do not use this prototype on an untrusted shared device. Avoid putting bank credentials, identity documents, or sensitive dispute details in notes. Only import records you are authorized to handle.

Delete or move your data

You can delete individual invoices in the workspace. To remove all locally saved data, clear site data for this website in your browser settings. Export a JSON backup first if you may need it. The hosted site and an offline HTML copy use separate browser storage; a backup file is the way to move work between them.

Questions or corrections

Use the public feedback form on GitHub. It requires a GitHub account. Do not include real customer or invoice data in a public issue.
