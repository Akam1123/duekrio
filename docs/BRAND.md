# Brand check before promotion

PromiseLedger is the working product name. A different public software project already uses that exact name for a customer-commitment tracker: [source repository](https://github.com/vsrikar08/promise-ledger) and [hackathon listing](https://www.compiled.sh/articles/gstax-x-gbrain-hackathon-1). That creates a real discoverability and confusion risk. It does not establish trademark infringement or ownership.

No external promotion is currently authorized. Before a future campaign, check the intended name against [USPTO trademark search](https://www.uspto.gov/trademarks/search), relevant non-US registers, domain records via [ICANN lookup](https://lookup.icann.org/), and current web results. "DueThread" is a preliminary alternate, not a cleared name.

If the visible name changes, retain the current browser storage key so users do not lose data. Keep the existing `/promiseledger/` site reachable or set a verified redirect before changing its path. Recheck canonical URLs, social images, docs, and the public demo after any rename.
