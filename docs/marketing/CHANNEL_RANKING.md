# Orvaket: ranked zero-cost distribution experiments

Reviewed 26 September 2026. The user authorized free promotion **after** `https://orvaket.pages.dev/` has a verified final deployment. That URL is the intended origin, not yet a verified live release at this update. No external post, listing, prospect contact, traffic, user, or revenue is claimed. Rankings are hypotheses about a small US B2B service firm's accounts-receivable operator, not measured conversion rates.

| Rank | Channel | Why and first bounded experiment | Cash and access gate | Evidence to keep |
| --- | --- | --- | --- | --- |
| 1 | **Owned site, useful guide, search discovery** | Verify indexing for the core free pages, add canonical sitemap in `robots.txt`, improve the existing weekly AR checklist with one real fictional-data screenshot and a clear link to the app. Answer a buyer task rather than produce a batch of keyword pages. [Google's sitemap documentation](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap) says submission is a hint, not a guarantee. | $0; site/repository access already exists. Search Console reporting requires a verified accessible property. | Live URLs and checks; search impressions/clicks only where observable; relevant inbound questions. |
| 2 | **GitHub repository and open-source directory** | Set an accurate repo description/topics and publish one free-version release. After confirming a usable app, public source, clear license, and documentation, submit one honest [Open App Scout](https://openappscout.com/submit/) record through its PR process. It can reject or defer it. | $0; authenticated repo access. Open App Scout requires a public GitHub repository and reviewable submission. | Release URL; directory PR URL and status; relevant referral or conversations if observable. |
| 3 | **Warm adviser introductions** | If an existing authorized bookkeeper/fractional-finance relationship is available, ask for a critique of the fictional workflow, then one *agreed* introduction to a firm with the problem. This may be the best qualified-buyer path, but cannot be fabricated from a contact list. | $0; real relationship, consent, sender identity and compliant contact route required. | Qualified buyer conversations, accepted pilot starts, second weekly use. |
| 4 | **Organic professional or community answer** | From an authorized existing profile, post one useful AR exception example or answer a specific relevant question. Explain maker relationship; link only where channel rules allow. [LinkedIn forbids unauthorized automation](https://www.linkedin.com/help/linkedin/answer/a1340567/automated-activity-on-linkedin?lang=en); [Reddit rejects repetitive unsolicited mass engagement](https://support.reddithelp.com/hc/en-us/articles/360043504051-Spam). | $0; authenticated legitimate account and each venue's current rules. No scraped leads, mass DMs or repeated links. | URL, date, relevant replies and opted-in conversations; impressions are diagnostic, not users. |
| 5 | **Product Hunt** | One direct-link, free-product listing only if a qualifying personal account already has access. The [official guide](https://help.producthunt.com/en/articles/479557-how-to-post-a-product) requires an individual account and accurate pricing; [account rules](https://help.producthunt.com/en/articles/771527-personal-account-vs-company-account) set a one-week age requirement and prohibit company accounts from posting. Broad maker reach may be less qualified than AR-specific paths. | $0; real personal identity, account age, launch assets, platform rules. No fake maker or coordinated votes. | Published post URL, substantive feedback, qualified conversations. |
| 6 | **Capterra basic listing** | Inspect [Capterra's current vendor path](https://www.capterra.com/vendors/) for a category that accurately describes the working free app. Request one basic listing only if onboarding can be completed truthfully without paid placement. Defer if the required vendor identity/category/account is unavailable. | No paid placement. Capterra's [main site](https://www.capterra.com/) distinguishes all-provider listings from sponsored profiles. | Request/submission ID and acceptance status; qualified referrals if available. |

The ordering reflects what is executable now as well as buyer fit. Warm advisers may produce stronger conversations than search, but no authorized adviser contact is currently established. A directory listing is exposure, not product validation. Paid Google/LinkedIn/Reddit ads are excluded by the zero-cash constraint. A Xero App Store listing would require a real approved integration, not a CSV import ([Xero partner guide](https://developer.xero.com/documentation/xero-app-store/app-partner-guides/building-and-growing-your-app/)).

For every attempt, check the live destination and rules immediately before publication. Keep the exact approved text, date, URL, account authority, result and effort in a private log; use `unknown` for metrics the app cannot observe. Never present public clicks, GitHub stars, directory views or votes as active app users. Avoid commercial cold email: [FTC guidance](https://www.ftc.gov/business-guidance/resources/can-spam-act-compliance-guide-business) says US B2B commercial messages are covered too, and local laws may also apply. The [measurement sheet](MEASUREMENT.md) and [first-customer plan](../GO_TO_MARKET.md) define actual validation signals.
